# Deep Learning for Computer Vision

A 5-month research training program covering deep learning foundations and research.

🌐 **Course Portal: [https://changliu816.github.io/cv-course/](https://changliu816.github.io/cv-course/)**

## Program Structure

| Phase | Duration | Content |
|-------|----------|---------|
| Coursework | Month 1 – 1.5 | 3 modules of lecture notes + 3 assignments |
| Research Onboarding | Month 1.5 – 5 | Robust fine-tuning (WiSE-FT / FLYP) on iWildCam |
| Independent Research | For advanced students | Self-directed research topic |

## Contents

- **Modules** — Lecture notes: image classification, neural networks, transformers
- **Assignments** — 3 assignments with starter code
- **Research** — Paper reading + reproduction notebook (RFT)
- **Resources** — d2l.ai, 周志华课件, setup guides
